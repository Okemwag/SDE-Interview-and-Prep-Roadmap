# AI Engineering

This folder covers topics for AI Engineering interviews and preparation — building, deploying, and maintaining systems powered by machine learning models and large language models (LLMs).

## Topics

- **Machine Learning Fundamentals** — supervised/unsupervised learning, evaluation metrics, overfitting and regularization
- **Deep Learning** — neural networks, backpropagation, CNNs, RNNs, transformers
- **Large Language Models (LLMs)** — architecture, tokenization, prompting, fine-tuning, evaluation
- **Retrieval-Augmented Generation (RAG)** — embeddings, vector databases, chunking, retrieval strategies
- **AI Agents** — tool use, function calling, orchestration, multi-agent systems
- **MLOps / LLMOps** — model serving, monitoring, versioning, CI/CD for ML, cost optimization
- **AI System Design** — designing scalable inference pipelines, latency/throughput trade-offs, caching, guardrails and safety

## Contributing

Add a markdown file per topic (e.g. `RAG.md`, `Transformers.md`) with explanations, diagrams, code samples, and interview questions — following the pattern used in the other folders of this repository.
